# 日向三國志 開発資産管理

## 方針

完成した武将画像は、チャット内だけで保管せず、このリポジトリを正式な資産庫として管理する。

- 正式肖像: `sangokushi/assets/portraits/`
- ミニ肖像: `sangokushi/assets/portraits/mini/`
- 円形アイコン: `sangokushi/assets/portraits/icons/`
- 対応データ: `sangokushi/assets/data/portraits.json`

ゲーム側は武将名から直接ファイルを推測せず、必ず `portraits.json` を参照する。

## 制作ルール

1. 一度に制作するのは一人だけ。
2. ユーザー承認前の画像は `review` とする。
3. 承認後に正式肖像、ミニ肖像、アイコンを書き出す。
4. 3種類のファイルとJSONを同じコミットで更新する。
5. 画像読込失敗時に旧SVGへ戻さず、明確な代替表示を行う。
6. 命令選択画面では大型画像を出さない。
7. 命令結果・軍師助言には、同じ正式肖像から作ったミニ肖像を使う。
