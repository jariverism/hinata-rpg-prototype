# 日向戦記 ―陽だまりの旗―

『日向三國志』『日向坂RPG』とは別系統の、章立て型SRPGプロトタイプです。

## 現在の実装

- 序章「目覚めた陽光」
- 14×11マップ
- 佐々木久美、加藤史帆、齊藤京子
- 潮紗理菜の会話加入
- 移動範囲・敵危険範囲
- 剣槍斧の三すくみ
- 地形補正、命中、必殺、反撃、追撃
- 戦闘予測
- 敵AI
- 村訪問、城門制圧
- LocalStorageセーブ／読込
- iPhone Safari向けタッチUI

## 起動

`index.html` をブラウザで開くだけで動作します。

## セーブキー

`hinata-senki-save-v1`

既存プロジェクトのセーブデータとは完全に分離しています。
