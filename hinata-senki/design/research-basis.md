# 日向戦記　物語・マップ設計基準

この文書は、今後の章を制作する際に共有する設計基準である。公開時の説明には具体的な加入人物、所属、敵味方、後半の真相を記載しない。

## 2. 人物分析の優先順位

一つの数値だけで兵種を決めない。以下を合成して判断する。

1. 公式の役割・実績
   - キャプテン、センター、ユニット、得意分野、番組での役割。
2. 公開された能力資料
   - 50m走、学力テスト、運動企画、クイズ企画。
3. 本人の印象と物語上の役割
   - 前衛、後衛、支援、参謀、斥候、交渉役など。
4. メンバー間の関係
   - 同期、公式ユニット、シンメ、家族的ユニット、仲間かつライバル、先輩後輩。
5. ゲーム全体の兵種バランス
   - 同じ兵種が集中しないよう、本人らしさを残した範囲で差別化する。
6. 長編内で必要な人物弧
   - 加入理由だけでなく、加入後に失敗する弱点、関係者との衝突、終章での回収まで先に決める。

### 数値の主な反映先

| 資料 | 主に反映する能力・適性 |
|---|---|
| 50m走 | 速さ、回避、追撃、騎兵・剣士・盗賊・飛行適性 |
| 学力テスト | 技、魔力、魔防、軍略・魔道・杖適性 |
| キャプテン・まとめ役 | 統率、指揮範囲、支援効果、ロード適性 |
| センター・表現力 | 魅力、幸運、再行動・士気支援 |
| スポーツ経験 | HP、力、守備、前衛適性 |
| 写真・芸術・観察力 | 技、命中、弓・偵察適性 |
| 個性的な発想 | 特殊魔法、状態異常、トリックスター適性 |

数値資料は人格や知能を断定するものではない。ゲーム上の適性を作る一要素に限定し、公開活動で示された役割と物語上の必要性を優先する。

## 3. 加入イベントの必須要件

日向坂メンバーを新しく配置する場合、次を事前に決める。

- 転生後、どこで誰に保護され、何をして生活してきたか。
- その土地や所属勢力に残る理由。
- 主人公側とすぐ合流できない障害。
- 最も自然な説得者と、その関係の根拠。
- 説得だけで足りるか、救出・訪問・敵将撃破などの前提が必要か。
- 加入後に本人が部隊へ残る積極的理由。
- 章終了時または次章開始時のフォロー会話。
- 加入後二章以内に起きる、本人の弱点に由来する問題。
- 中盤または終盤で、加入時の弱点を反転させる決断。

### 加入方法のバリエーション

- 関係の深い仲間による直接説得。
- 一度話した後、民間人救出などを達成して再度話す二段階説得。
- 特定の村を特定人物で訪問する。
- 敵として戦うが、特定人物との初戦闘会話後は攻撃をやめる。
- 一定ターン守り切ると、相手側から話しかけてくる。
- 倒さずに敵将を退ける、または特定部隊を生存させる。
- 二人の関係者が別々の目標を達成して初めて加入意思が固まる。
- 早期加入条件を逃しても章終了時に合流し、永久離脱はさせない。

## 4. 長編プロットの構造

全体は20章を基本とし、四つの段階に分ける。

- 第一段階：逃走と小部隊形成
  - 世界、国家、敵勢力、主人公側の短期目標を理解させる。
  - 再会しても昔の関係だけでは加入しないことを示す。
- 第二段階：地方勢力との接触と反攻準備
  - 各地の事情を解決し、同盟と軍資金を得る。
  - 仲間が増えるほど意見が割れ、関係性が作戦上の長所と弱点になる。
- 第三段階：王都への帰還と戦争の真相
  - 単純な王国奪還では解決しない対立を示す。
  - 王国側の罪、指揮官の限界、知識型人物の方法論対立を描く。
- 第四段階：複数国家を巻き込む最終局面
  - それまでに築いた関係、加入、村の救済、取得物が戦況に影響する。
  - 同じ過去を持つからではなく、異なる現在から同じ未来を選ぶ結末へ進む。

各段階で、個人の加入物語と国家規模の主筋が交差するようにする。

## 5. マップ設計の原則

各章は最低一つ、できれば二つの固有テーマを持つ。

- 一本道で敵を全滅させるだけの章を連続させない。
- 勝利条件を、制圧、脱出、防衛、救出、到達、複数拠点確保、護衛などから選ぶ。
- 主経路と危険な近道を用意する。
- 村・宝箱・店は主目的から少し外れた位置に置き、分隊判断を作る。
- 増援は予告会話、砦、階段、船着場など、出現理由が見える場所から出す。
- 飛行・騎兵・盗賊・杖・弓など、その章で活躍する兵種を意図的に作る。
- 説得対象は、倒してはいけない危険と、救うために進軍する価値の両方を持たせる。
- 章開始会話で地形と目的を説明し、民家会話で攻略のヒントと世界設定を伝える。
- 人物の弱点をマップ上のジレンマに変える。例として、俊足者の単独突出、守備者の持ち場固執、知識型の準備過多、家族的支援者の囲い込みを、配置と勝利条件で試す。
- 関係性は命中補正だけでなく、説得、同時操作、別部隊間の合図、救援優先順位へ反映する。

## 6. 情報の確度

人物関係には次の確度を付ける。

- A：公式ユニット、公式ブログ、本人同士の公開発言。
- B：主要媒体の対談・インタビュー、番組で継続的に示された関係。
- C：同期・同学年・同じ活動経験などから自然に推測できる関係。
- D：ファン相関図や単発の印象。単独では加入条件の根拠にしない。

ゲーム内の強い説得関係は原則AまたはBを用い、Cは補助、Dは会話の小ネタに限定する。

## 7. パーソナリティを台詞へ反映する基準

全員を同じ英雄口調にしない。各人物について次を `internal-character-story-bible-v2.md` に固定する。

- 普段の言葉の長さと速度。
- 緊張した時に言葉が増えるか減るか。
- 感情を直接言うか、冗談、行動、比喩へ逃がすか。
- 危機で最初に見る対象が、人、地形、規則、情報、退路のどれか。
- 信頼する相手にだけ見せる弱さ。
- 加入時の弱点と、終章で反転する判断。

台詞は口癖の模倣だけで本人らしさを出さない。判断、沈黙、失敗、誰に相談するかによって区別する。

## 8. 肖像画像とシナリオの分離

- 肖像が未完成でも、物語上必要な人物は予定どおり登場・加入させる。
- 仮表示は名前、兵種アイコン、固有色を使い、他人物の肖像を流用しない。
- 肖像制作の順番を、登場章や物語上の重要度へ影響させない。
- 画像の完成後も、外見に合わせて既存の人格、兵種、加入理由、章順を変更しない。
- 集合画像は参考資料に限定し、個人肖像のマスターやシナリオ判断へ使わない。
