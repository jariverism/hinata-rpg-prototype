# 日向坂クエスト0　ハッピーオーラを求めて

第一章「空色の騎士団長」を最後まで遊べる、依存ゼロの静的ブラウザJRPGです。

## 公開パス

GitHub Pagesの公開元がリポジトリ直下である場合：

`https://jariverism.github.io/hinata-rpg-prototype/hinata-quest-zero/`

## 操作

- 移動：矢印 / WASD / タッチ十字キー
- 決定・会話：Enter / Z / Space / A
- メニュー：Esc / X / M / MENU

## 収録内容

- タイトル、名前入力、現代日本からの異世界転生
- 草原、王都、洞窟の見下ろしマップ
- NPC会話、宝箱、道具屋
- 追跡型シンボルエンカウント
- 主人公と佐々木久美のコマンド式ターン制戦闘
- 経験値、レベルアップ、薬草、装備
- ボス「笑顔喰らい」
- オートセーブと3つの手動セーブ
- PC、タッチ、ゲームパッド操作
