# 日向坂クエスト0 Re:build

## ハッピーオーラを求めて

初期の王道JRPGが持つ「町で噂を集め、装備を選び、未知の場所へ踏み込み、
危険なら戻る」という冒険の手触りを、オリジナルの世界・キャラクター・
ピクセルアートで再構築した静的ブラウザゲームです。

第一章「空色の騎士団長」から第四章「疾風の剣士と蒼天の塔」まで、
一つの世界とセーブデータで地続きに遊べます。

## 公開URL

<https://jariverism.github.io/hinata-rpg-prototype/hinata-quest-zero/>

## 操作

- 移動：矢印キー / WASD / タッチ十字キー / ゲームパッド
- 決定・会話・足踏み：Enter / Z / Space / Aボタン
- 戻る：Escape / X / Bボタン
- メニュー：M / MENUボタン

## 実装したもの

- 20×11画面に固定しない、カメラ追従式の大型スクロールマップ
- 地続きの街道から選べる、王都・こだまの森・忘れ井戸・空泣き洞
- 固有形状の22マップ、三層の空泣き洞、二層の地下穀倉、無音の神域、風哭きの塔
- 18人以上の町人から得る噂・弱点・隠し道の情報
- 常時「次の目的」を表示しない噂帳。クラシック・標準・ガイドの3モード
- 4つの任意サブクエスト、隠し宝、採取、ショートカット
- 複数の敵、対象選択、行動順、弱点、状態異常を持つコマンド戦闘
- 久美の号令、光鳴りの鈴、取り巻き撃破など複数解法を持つボス
- 武器・盾・身体・装飾の4装備枠
- 購入・売却、宿屋、礼拝堂、所持金を使う準備の選択
- シンボルの索敵・追跡、先制、不意打ち、逃走、再出現
- 発見時の警戒猶予、その場での足踏み、正面／背後を区別する公平な接敵
- 敵の行動予告と固有パターン、弱点で崩せる防御、抑えた経験値曲線
- 一度きりの野営、消耗する対策道具、持越し上限のあるハッピーゲージ
- ソラシド近郊西端からロードなしで接続する陽だまり街道とパンの国ミレリア
- 黄金麦・清水・酵母を任意順に探す第二章メインクエスト
- 焼き方でボス対策・消耗品・最大HPが変わるパン作り
- 回復・状態治療・炎の守り崩しを担う佐々木美玲の正式加入
- 新規敵7種、任意の中ボス、予告全体攻撃と二本の根を持つ第二章ボス
- ミレリア南端からつながる虹風の峠、精霊樹の里サリナリア、三響の森
- 水・風・光の三試練を任意順で攻略し、精霊の会話から正しい音色を推理する探索
- 回復・属性防御・全体支援を担う潮紗理菜の正式加入と、四人パーティ戦闘
- 属性共鳴の順を読み、二つの封印像を崩して戦う第三章ボス「無響獣サイレント」
- 虹風の峠南東からつながる天翔け街道、風の街カトシア、蒼天闘技場、二層の風哭きの塔
- 守り・速さ・魔法の三予選を好きな順で攻略できる第四章メインクエスト
- 二連撃で構えを崩し、予告技へ割り込む加藤史帆の正式加入
- 五人から最大四人を選ぶ前衛・控えのパーティ編成と、控えを含む装備変更
- 二経路の風向計、近道、風耐性装備を使って攻略する塔ダンジョン
- 二つの暴風眼、風圧障壁、反撃、予告大技を持つ第四章ボス「颶風鏡ヴェントラ」
- 第一〜三章の名前・レベル・経験値・能力・装備・所持品・所持金・進行の完全引継ぎ
- ハッピーゲージと連携必殺技
- オリジナルの手描きプロシージャル・ピクセルアート
- 場所別のオリジナル簡易チップチューンと効果音
- 3つの冒険の書、自動セーブ、全滅地点からの再出発
- PC・タッチ・ゲームパッド操作
- 旧v1〜v4セーブを消さず、名前・実績・記念装備へ移行
- 公開済みv5〜v7セーブを消さずに第四章へ継続

## 開発

```sh
npm install
npm run dev
npm test
npm run build
```

ランタイム依存のないES ModulesとCanvas 2Dで実装し、Viteは開発・検証・
本番ビルドにのみ使用しています。GitHub Pagesではリポジトリ内の
`hinata-quest-zero/`をそのまま公開できます。
